About Diagram Studio

    
Diagram Studio turns plain-English descriptions into Mermaid diagrams using a language model you choose: a local model through Ollama or any OpenAI-compatible API.

    
Privacy

    
Your prompts and diagram code are sent to the model provider configured by whoever runs this server. The app itself keeps no database and does not store prompts. Request logs record only the path, status and timing.

    
Accuracy

    
Diagram output is AI-generated and may contain errors. Check it before you rely on it.
